# Mini Weather App with ESP32-C3

A minimal weather app school project using ESP32-C3 OLED and Arduino framework within PlatformIO
I used U8g2 libray for graphics, ArduinoJSON for json deserialization, HTTPClient for fetching weather data from openweathermap com API, lopaka website for UI design

### Pin configuration

- Connect 1 tuct button(internal pull-up) to GPIO8 for Previous City action
- Connect 1 tuct button(internal pull-up) to GPIO9 for Next City action
